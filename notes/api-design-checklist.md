# API Design Checklist

Quick reference for designing new endpoints.

- [ ] Use nouns, not verbs, in URLs
- [ ] Prefer JSON over XML
- [ ] Version via URL prefix (`/v1/`)
- [ ] Return meaningful HTTP status codes
- [ ] Document error responses consistently
- [ ] Paginate list endpoints by default
- [ ] Include request IDs in headers
- [ ] Keep payloads flat when possible
